# CC0mon Pocket Catcher 🐾

A fun, single-file browser game where you catch **real CC0mon** from the official on-chain collection — with only **one attempt** per mon.

Built to celebrate the cute and weird pixel creatures of CC0mon while making the collection more approachable and fun for everyone.

## ✨ Features

- Real CC0mon pulled directly from the official API (tokens 1–10,000)
- Classic one-try catching mechanic with genuine tension
- Harder catch rates — Mythic and Legendary mons are rare and challenging
- Successful catches are automatically added to your personal pocket
- Direct "View on OpenSea" links for every caught mon
- Share your catches directly to X (Twitter)
- Export your entire pocket as a JSON file
- Fully client-side — nothing is stored on any server
- Retro sound effects and smooth animations

## 🎮 How to Play

1. Click **"GO ON A WALK"**
2. A wild CC0mon appears
3. Click **"THROW CRYSTAL"** — you only get **one chance**
4. If you catch it → it’s automatically added to your pocket
5. Check your pocket, export it, or buy the real NFT on OpenSea

## 🚀 Quick Start

1. Download `index.html`
2. Open the file in any modern browser (Chrome, Firefox, Edge, Safari)
3. Start catching!

No installation, no build step, no dependencies.

## 🛠 Built With
